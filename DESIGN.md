# NK QBank interaction direction

Read [AGENTS.md](AGENTS.md) first. Canonical product context is
[.project-memory/PRODUCT.md](.project-memory/PRODUCT.md); `PRODUCT.md` points there.

This is refinement of the existing Operate interface. Preserve its light study
surfaces, violet primary actions, existing type, source-native study content,
semantic answer colors, fixed question footer and responsive navigation.
No replacement visual system or new product architecture is authorized.

Interactions acknowledge the action immediately. Durable question commits still
precede success feedback. No animation, debounce, timeout or transition gates an
answer, navigation, filter or save. Repeated question solving stays quiet:
preserve current haptics, immediate press feedback and in-place CBT/rating/bookmark
updates. Preserve reduced-motion feedback without spatial movement.

Priorities: keep the question and its figures mounted during answer feedback;
give outcomes a readable text label; keep filter controls, keyboard focus and
reading position stable; enlarge small common targets; keep dense charts useful
with keyboard access. Familiar native subject/bank pickers remain appropriate.

Audit, implementation and validation evidence:
[docs/INTERACTION_QUALITY_2026-10-03.md](docs/INTERACTION_QUALITY_2026-10-03.md).
