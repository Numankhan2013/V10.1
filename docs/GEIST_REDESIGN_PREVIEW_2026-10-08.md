# Geist redesign preview (2026-10-08)

Status: preview-only candidate on `feature/home-geist-redesign`. Not accepted, not for main or production.

## What it is
A presentation layer over the unchanged V11.6/V11.7 app (main `07f6e8c`):
- `app/src/main/assets/redesign/nk-tokens.css` — neutral light/dark semantic tokens, Geist @font-face.
- `redesign/nk-theme.css` — generated by `tools/redesign_generate_theme_css.py`; maps legacy colours/radii/fonts onto tokens, scoped to `html[data-nk-ui="geist"]`.
- `redesign/nk-redesign.css` — component layer (top bar, nav, Home, More, Profile, charts, motion, reduced-motion).
- `redesign/nk-redesign.js` — UI switch (`?ui=geist|legacy`, `nkq.ui`), theme Light/Dark/System (`nkq.theme`), Phosphor icon swap, top bar, Appearance controls, local Profile at `#profile`, native haptics bridge.
- Vendored offline: Geist/Geist Mono (OFL), Phosphor 2.1.1 icons (MIT).

## Guarantees
- No study logic, renderer, storage schema or sync change. index.html gains only asset tags; sw.js precaches the new files.
- Under browser automation (`navigator.webdriver`) the legacy look stays, so existing contract suites are unchanged. Use `?ui=geist` to force the new look.
- Profile name is device-local; stats reuse the app's own counters.

## Known limits
- `#profile` briefly shows the dashboard before Profile renders.
- Timed CBT, Review Solutions and PDF figures need visual review on the deployed preview.
