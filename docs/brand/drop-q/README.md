# Drop-Q — Mind QBank mark (candidate C1)

Status: **candidate, not approved, not wired into the app.** Replaces the B5 "hook-tail" working candidate.

A Q whose tail is a single drop pinching off the ring: the ring is the mind, the drop is one fact settling into memory.

## Geometry (100-unit grid)
- Ring: outer Ø72 centred (46, 46); counter Ø34 offset (−2.5, −2.5) so weight sinks toward the drop.
- Drop: Ø25 at 45°, centre 44 units from the ring centre.
- Neck: 12-unit metaball fillet between ring and drop.

Regenerate every SVG with `python3 build.py` (needs `geo.py` alongside). PNGs are 1024 px renders of the SVGs.

## Files
- `drop_q_mark_{black,white,ink}.svg` — transparent mark.
- `drop_q_icon_{light,violet,dark}.svg` — rounded app-icon tiles (mark spans 56%).
- `drop_q_icon_{light,violet}_square.svg` — full-bleed tiles for Android adaptive / PWA maskable icons.
