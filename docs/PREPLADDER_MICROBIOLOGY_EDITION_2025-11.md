# PrepLadder Microbiology — November 2025 edition merge (2026-10-17)

The coaching issued an updated edition of the PrepLadder Microbiology QBank,
generated on 18 November 2025, as four PDFs: `MicroPrep1.pdf`,
`Microprep-02.pdf`, `Microprep-03.pdf` and `Microprep-04.pdf` (2,303 pages,
48 lessons, 1,100 questions). It was extracted by an external agent and
merged onto Version X (1,042 questions), the edition learners first studied.

- Rules: `tools/prepladder_microbiology_edition.py`.
- Per-question decisions: `data/Prepladder/microbiology/source/edition_map.json`.
- Build: `tools/build_prepladder_microbiology_bank.py import-v2 <master.jsonl> <images>`.

## Which edition supplies what

| Part | Source |
|---|---|
| Options, order, answer key | Always the November 2025 edition. |
| Stem | Version X when the stem and options are unchanged, or when the new stem is only Version X's Match-the-following table flattened into text (Version X keeps the table: 35 questions keep stem tables). Otherwise the new edition. |
| Explanation | The new edition (749), except 454 that come from Version X. |
| Figures | Whichever edition supplies the stem or the explanation they belong to. |

The 454 Version X explanations break down as follows:
- **Same text (≥ 90% of words), answer unchanged:** Version X's structured
  blocks (tables, lists) are kept.
- **33 questions the new PDF leaves blank:** the PDF prints only
  "References: , , Prepladder Notes". Version X's explanation is used and the
  question carries a review note.

**Flattened text.** The new PDF is a flat text dump (generated by
`@Neet_pg_bot`): its tables and lists are already run together on the page,
so no extraction can rebuild them. New-edition explanations are shown as
paragraphs split at sentence ends. Each "Name (Option B) …" analysis gets
its own paragraph with a bold label, and a leading "Correct answer (X) …"
line is dropped.

## Lost characters (■)

The source PDF's font replaced some characters with a ■ placeholder. The
same placeholders were in Version X and were live until now.

**Restored from context:**
- CO₂, N₂, H₂O₂ and SpO₂;
- F⁻ (F-minus cells);
- CTXφ;
- 121 °C and 4 °C;
- group B β-hemolytic and gram-negative;
- Cryoglobulinemia and glomerulonephritis.

**Malaria ring-form table:**
- "Occupies 1/3rd of RBC size", wherever the text continues "rd".
- "Occupies a smaller fraction of RBC size" for the 1.5 µm falciparum ring.
  The source gives no value there, so none is invented.

**Dropped:** any remaining run of ■, which is a lost icon or bullet.

The bank test fails if a ■ reaches the learner.

## Verified against the PDFs

- **Answers.** The new edition's key matches the PDF's "Correct Answer" line
  for all 1,099 questions that print one.
  - `PREPLADDER_MICRO_L34_Q017` prints none: its four options are images that
    the PDF omits, and the extraction rebuilt them from the explanation. It
    keeps `needs_review`.
- **Options.** Options match the PDF text for all but three questions, and
  those three are ■ glyphs.
- **Figures.** The extraction's 1,431 Part 2–4 figures were missing from the
  delivery, so they were taken from the PDFs. Each was located by page and
  bounding box and saved as the embedded JPEG's original bytes, matching the
  manifest's pixel size. Part 1's 180 figures had already been checked byte
  for byte. The deterministic trimmer (`tools/figure_trim.py`) then removed
  thin borders as before. 1,552 figures are in use.
- **Matches.** The weakest matches (score 0.68–0.73) were read by hand. All
  are the same question with a Match-the-following table flattened into the
  stem.
